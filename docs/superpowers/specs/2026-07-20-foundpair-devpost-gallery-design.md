# FoundPair Devpost Gallery Design

## Goal

Create four polished, upload-ready Devpost project-media images from authentic FoundPair product screens.

## Selected approach

Use the existing browser captures from the deployed FoundPair MVP and present them in branded 3:2 cards. This is stronger and more honest for judging than generated UI mockups.

Alternatives considered:

1. **Branded product cards — selected.** Clear context, consistent visual system, and real UI evidence.
2. **Raw screenshots.** Most literal, but less legible and less polished in the gallery.
3. **AI-generated promotional art.** Visually dramatic, but weaker evidence of what was actually built.

## Deliverables

Create these 1800×1200 PNGs in `/Users/athifshaffy/Desktop/FoundPair-Devpost-Gallery/`:

1. `01-explainable-matching.png` — landing page and core value proposition.
2. `02-founder-context.png` — skills, needs, values, and logistics inputs.
3. `03-ranked-matches.png` — ranked compatible cofounders with visible fit bands.
4. `04-compatibility-details.png` — strengths and potential friction explained.

Every file must remain under Devpost's 5 MB image limit.

## Visual system

- 3:2 canvas with cream background.
- FoundPair indigo, coral, and lime accent blocks.
- Bold headline and short factual caption above the screenshot.
- Screenshot in a dark bordered frame with a subtle offset shadow.
- No browser chrome, personal data, passwords, API keys, or claims beyond the deployed MVP.

## Verification

Verify all four files are PNG, exactly 1800×1200, below 5 MB, visually legible, and based on the existing deployed-product captures.
